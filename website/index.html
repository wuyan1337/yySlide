Mobile Terminal

人在外面，也像坐在服务器前。

Android 端保留终端快捷键与干净的深色命令行体验。Esc、Tab、Ctrl、Alt、Paste 都在手边，临时排障不用再找电脑。

  • 移动端 SSH 终端，适配长输出与快捷键栏
  • 连接、终端、文件、设置四个核心入口
  • 适合随手检查服务状态、重启、看日志
$ systemctl status yyslide-cloudactive · encrypted sync online

Desktop Control Center

终端、监控、文件，一个窗口解决。

桌面端像一块服务器驾驶舱：左侧看机器状态，中间敲命令，下方处理文件传输。少切窗口，少开网页。

实时监控

SFTP 文件工作流

路径、文件表、上传下载队列放在同一个视图，处理配置和日志更直接。

多端一致

yySlide Cloud
