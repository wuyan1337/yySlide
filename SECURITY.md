# Security Policy

## Supported versions

Security fixes are made on the default branch and included in the next yySlide release. Older builds may not receive backports.

## Reporting a vulnerability

Please use GitHub's private vulnerability reporting feature for this repository. Do not open a public issue for vulnerabilities that could expose credentials, private keys, synced vault contents, or user data.

Include affected versions, reproduction steps, impact, and any suggested mitigation. Remove real credentials and personal data from logs or examples.
